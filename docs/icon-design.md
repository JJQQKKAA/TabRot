# TabRot icon

The icon uses a simple tab outline, two reading lines, and a warm amber age marker. It echoes the marker added to website favicons.

- Transparent background; no dark square.
- Green outline (`#40805b`) with a pale mint interior (`#f0f8f2`).
- Amber marker (`#efb75b`) with a white separating ring.
- Editable vector source: `icons/icon.svg`.
- Chrome assets: 16, 32, 48, and 128 px PNG; 512 px preview: `icons/icon-master.png`.

This revision is drawn directly in SVG, with no generated raster dependency. Regenerate the PNGs using `node tools/icons.mjs` with the optional `sharp` package installed.
