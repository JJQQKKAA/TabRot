# TabRot · 待读时光

一个安静的 Chrome 阅读提醒插件。网页搁置越久，favicon 右下角的颜色标记越深，让你记得回来看好内容。

原生 JavaScript / HTML / CSS，Manifest V3，无构建步骤，无服务器、账号、分析服务或云同步。

## 安装

1. 打开 Chrome，进入 `chrome://extensions`。
2. 打开右上角「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择本项目根目录（包含 `manifest.json` 的目录）。
4. 在工具栏的扩展菜单中固定 TabRot。点击图标即可打开待读架。

也可以解压 `dist/TabRot-v1.1.0.zip` 后，加载解压后的目录。插件会自动接管已打开的普通网页，不需要逐个刷新；受保护页面和浏览器 PDF 阅读器可能无法修改图标。

## 使用

默认使用英文界面。Popup 右上角点击「中文 / EN」可即时切换，也可在设置页选择语言；偏好仅保存在本机。紧凑列表在 420×580 窗口内可完整显示至少 7 个标签。

- **自动追踪**：普通 HTTP / HTTPS 网页默认进入待读架，首次发现时开始计时。
- **时间显色**：默认在 30 分钟、2 小时、6 小时、12 小时、1 天、3 天、7 天、30 天设置颜色节点，节点之间按对数时间连续插值，每分钟更新一次。
- **阅读由你决定**：点击「✓ 已读」移除颜色提醒，在「已读」中可重新标记未读。切换、滚动或停留不会自动变为已读。
- **稍后提醒**：条目的「•••」菜单支持 1 小时后、明天本地时间 09:00、3 天后。到期恢复基于原始打开时间的颜色，不发送通知。
- **忽略**：支持单个标签、整个域名及其子域名；默认忽略固定标签。单标签忽略在列表中取消，域名和固定标签规则在设置中管理。
- **设置**：调整八个递增的时间节点、忽略网站、是否忽略固定标签，或重置全部本地数据。

列表支持标题和网址搜索、状态筛选、打开时长倒序排列，点击标题可切换窗口和标签。

## 计时与恢复约定

- 刷新、切换标签、同一网页内的 `#fragment` 跳转不会重新计时。
- 路径或查询参数变化视为另一篇内容，重新计时；包括单页应用中的 URL 变化。
- 关闭单个标签会删除记录。关闭窗口的记录短暂保留，以便正常退出 Chrome 后恢复。
- 重启后使用保存的网址、窗口和标签位置进行一对一匹配；相同网址的多个标签可能无法恢复到完全相同的身份，属于尽力恢复。
- 启动后保留两分钟恢复窗口，之后清理无对应标签的记录；不构建长期浏览历史。
- 后台由浏览器事件和一分钟一次的 alarm 驱动。设备休眠或 Chrome 限制定时器时，更新可能推迟至恢复运行。
- 页面持续替换 favicon 时会观察相关 DOM 变化并重新叠加标记；失败时保留原站点图标。列表中的追踪和状态操作仍然可用。

## 权限与隐私

- `tabs`：读取当前打开网页的标题、网址、位置，并切换标签。
- `storage`：本地保存时间、阅读状态和设置；会话存储用于保存本次浏览器运行中的 Tab ID 映射。
- `alarms`：低频更新颜色和到期状态。
- `scripting` 与 HTTP / HTTPS 网页访问：向已打开网页注入 favicon 标记逻辑，并读取网页原有图标用于合成。图标请求不携带登录凭证或 referrer。

不读取正文来分析阅读行为，不访问云端分析服务，不上传浏览记录。Chrome 会提示网页访问权限，因为修改 favicon 需要访问页面。

## 开发和验证

```sh
npm test
npm run check
```

上述检查不需要安装依赖。测试覆盖颜色插值、域名边界、状态优先级、暂停时间、重复网址匹配、Service Worker 状态恢复、导航重置、关闭清理及消息来源校验。

可选的真实 Chrome 扩展端到端测试（仅开发时需要 Playwright）：

```sh
npm install --no-save playwright
npx playwright install chromium
node tools/browser-smoke.mjs
```

测试使用独立临时配置和本地网页，不接触日常浏览器资料，完成后删除测试配置，界面截图输出至 `docs/`。如需指定已有 Playwright，设置 `PLAYWRIGHT_MODULE_PATH`；浏览器下载位置可通过 `PLAYWRIGHT_BROWSERS_PATH` 指定。

打包：

```sh
python3 tools/package.py
```

## 目录

- `src/core.js`：颜色、状态、网址身份和恢复匹配等纯逻辑。
- `src/background.js`：事件驱动的后台、持久化、消息和低频更新。
- `src/content-v1.0.2.js`：原 favicon 保存、颜色标记合成、动态更新和还原。
- `src/popup.*`：待读架。
- `src/options.*`：设置页。
- `icons/`：实际插件图标与原始大图，设计说明见 `docs/icon-design.md`。

更新本地代码后，在 `chrome://extensions` 点击 TabRot 的「重新加载」。若已打开的网页仍运行旧版本的内容脚本，请刷新相关网页；Chrome 错误列表中的历史记录可手动清除。
